# 🚗 Rent a Car Liridoni

Faqe profesionale për **Rent a Car Liridoni** — makina moderne me qira në Tiranë me
çmime të volitshme, sigurim të plotë dhe dorëzim 24/7.

## 🌐 Publikimi

Faqja publikohet **falas** në internet përmes **GitHub Pages**.

- 📖 **Udhëzues hap-pas-hapi:** hap skedarin [`README-GITHUB-PAGES.md`](README-GITHUB-PAGES.md)
- 🧭 **Alternativë me Google Sites:** hap skedarin [`README-GOOGLE-SITES.md`](README-GOOGLE-SITES.md)

## 📁 Struktura

```
rentacar-liridoni/
├── index.html                  → Faqja e plotë (HTML + CSS + JS në një skedar)
├── README.md                   → Kjo faqe
├── README-GITHUB-PAGES.md      → Udhëzuesi për GitHub Pages
├── README-GOOGLE-SITES.md      → Udhëzuesi për Google Sites
├── .nojekyll                   → Siguron që GitHub Pages ta shërbejë HTML-in direkt
```

## 🚀 Si ta shikosh lokalisht

Hap skedarin `index.html` me dy klikime:

```
start index.html
```

ose hape nga VS Code → **Live Server**.
